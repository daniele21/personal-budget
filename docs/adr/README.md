# ADR index

Accepted Aura architecture decision records are canonically stored in the repository-root `/adr/` directory. Keep that location as the single ADR source of truth; this file exists only to satisfy repository documentation routing and prevent a duplicate ADR tree.

Current ADRs cover the portable archive, Android Capacitor runtime, payment-candidate acceptance/detection release boundaries, account deletion orchestration, Android-only distribution and cloud-backup retention. Add new accepted decisions to `/adr/` using the existing numbering/style.
