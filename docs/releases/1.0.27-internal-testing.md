## User-visible scope — mitigated unconfirmed binding requests, not proven Samsung root-cause resolution

- [PR #82](https://github.com/daniele21/personal-budget/pull/82): process-local, per-generation control of repeated requests to bind a **missing** Android NotificationListenerService. A successful static `requestRebind` invocation remains an **unconfirmed request**, not proof that Android actually started or connected the service.
- Missing-endpoint retries are coalesced using a bounded monotonic 30-second / 60-second / 2-minute / 4-minute / 5-minute capped interval, without permanent abandonment of the enabled detector. Concurrent foreground/worker requests cannot submit a storm of identical binding requests. Failed platform API calls remain eligible for WorkManager's existing retry path.
- New diagnostic status `BIND_WAITING` reports that the latest recovery pass deferred another bind request. Existing `BIND_REQUESTED` still reports a submitted asynchronous request. Content-free diagnostics expose separate **recovery attempts**, **bind requests submitted**, and **bind requests deferred**; the UI no longer treats all recovery passes as actual requests when the new native fields are available.
- The process-local limiter is reset on genuine `onListenerConnected` registration, owner/reset boundary, disabled detection or lost access. The implementation preserves the opt-in and selected-source privacy gate, encrypted local candidates and review-before-ledger rules.
- Earlier merged foundation: [#76](https://github.com/daniele21/personal-budget/pull/76) execution plan, [#80](https://github.com/daniele21/personal-budget/pull/80) read-only/redacted ADB evidence helper, [#81](https://github.com/daniele21/personal-budget/pull/81) synthetic zero-binding diagnostic regression. The command-line evidence helper is **not** shipped as a handset UI feature.

**Non-goals:** No change to parser matching, banking notification contents, supported-source filtering, Room/ledger migrations, Android permissions, accessibility service, or production rollout. This release does **not** establish the reason the Samsung Galaxy A56's Android NotificationManager previously failed to start or connect the V2 listener.
