# Aura 1.0.8 (11) — Internal Testing

## Release name

`Aura 1.0.8 (11) — Mobile onboarding & backup history`

## Track

Google Play Internal Testing only. Payment detection remains beta-only and the
build must not be promoted to production while the privacy, physical-device and
whole-app release gates remain open.

## Google Play release notes — English

Aura now has a shorter mobile setup, five encrypted cloud-backup versions and
small contextual tours you can start when needed. The app no longer shows web
installation prompts, and reminders use the native Android notification path.
This update also improves offline startup, account-deletion access and mobile
accessibility.

## Note di rilascio Google Play — Italiano

Aura ora offre una configurazione mobile più breve, cinque versioni cifrate del
backup cloud e piccoli tour contestuali da avviare quando servono. Rimossi i
prompt di installazione web; i promemoria usano il canale notifiche nativo
Android. Migliorati anche avvio offline, accesso alla cancellazione account e
accessibilità mobile.

## Scope and known gates

- First-run setup requires a positive monthly budget in the real setup path;
  demo remains an explicit alternative.
- Cloud backup migrates legacy single/three-slot history to up to five managed
  encrypted versions on the next successful push.
- PWA installation, manifest, service worker and browser notification delivery
  are retired; React/Vite remains bundled in the Android package.
- Native notification permission, immediate delivery, redaction, allowlisted
  deep links and cancellation are implemented. Persistent future scheduling
  across reboot/timezone remains an open gate.
- Rollback requires a replacement artifact with a higher `versionCode`; backup
  V2 retains root compatibility data for older readers.
