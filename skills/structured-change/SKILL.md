# Structured Change
State **observable outcome, canonical owner, invariants and proof**. Inspect direct consumers/projections/tests and establish failing evidence for reproducible bugs when practical. Extend existing domain/data/orchestration/platform/UI owners; preserve deterministic finance semantics, explicit transaction confirmation, encrypted opt-in backup, credential/signing isolation and bounded native lifecycle. Use `validate-change` during implementation; `preflight-change` owns integration/release readiness.
