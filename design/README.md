# Aura product-experience contract

Aura is code-first for product UI. `design/ux-contract.json` records stable UX semantics and routes implementation to `src/pages/`, `src/components/`, `src/platform/` and the existing product/QA evidence. `design/brand-kit.json` maps the machine-readable contract to the canonical visual guidance and assets in `brand-kit/`.

Do not create a second design system in this directory. Meaningful structural/interaction changes should follow `skills/design-product-experience/SKILL.md`; visual-only changes should reuse the established code/brand owners and preserve settled user-task semantics.
